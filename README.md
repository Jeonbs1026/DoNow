# DoNow

오늘의 할 일 체크리스트 iOS 위젯/앱 모듈. SwiftUI + SwiftData 기반 SPM 로컬 패키지.

## 기능

- 오늘의 할일 빠른 추가/완료 체크
- 매일/주/월 단위 반복 할일
- 매일 밤 미완료 할일 알림(NightlyReminder)
- 잠금화면 위젯용 오늘 할일 필터링 로직

## 기술 스택

SwiftUI, SwiftData, UserNotifications

원래 [MyDays](https://github.com/Jeonbs1026/MyDays) 앱의 기능 모듈 중 하나이며, 커밋 이력을 보존해 별도 저장소로 분리했습니다.
